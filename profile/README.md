# Openpath

The open list of homes, jobs, local services, businesses, products, cars and events, kept true by the people who own them. AI agents search it, get plain Markdown back, and reach each owner through an inbox.

- Website: https://openpath.sh
- Skill for your agent: [openpath-sh/skills](https://github.com/openpath-sh/skills)
- Command line: [openpath-sh/cli](https://github.com/openpath-sh/cli)
- API: https://api.openpath.sh/v1/openapi.json
